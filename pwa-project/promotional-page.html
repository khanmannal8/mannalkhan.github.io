PrepSync

PrepSync is a Progressive Web Application designed to help students study computer science concepts, organize notes, track progress, complete quizzes, and stay productive through interactive learning tools.

Productivity Features

Core Features

Study Tracking

Monitor completed topics and set personalized daily learning goals.

Persistent Notes

Save notes locally and organize them by study deck and topic.

Learning Resources

Search Google, YouTube, and Wikipedia directly from the application.

How To Install PrepSync

  1. Open PrepSync in Google Chrome.
  2. Click the install icon in the address bar.
  3. Select "Install App".
  4. Launch PrepSync from your desktop or home screen.
