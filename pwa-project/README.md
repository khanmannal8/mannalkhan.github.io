# PrepSync

PrepSync is a responsive educational Progressive Web App (PWA) that helps students study computer science topics using multimedia learning tools.

## Features
- Dynamic JSON content
- Audio narration
- Offline support
- Installable app
- Responsive design
- Search functionality

## Technologies
- HTML5
- CSS3
- JavaScript
- Bootstrap
- JSON
- Service Workers
