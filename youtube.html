Educational Technology Videos

1. HTML & CSS Crash Course

This video is an introduction to HTML and CSS, which are the foundational languages used to create websites. HTML is used to structure content on a webpage while CSS is used to style and design the page.

The instructor explains important beginner concepts such as:

  • Headings and paragraphs
  • Adding images and links
  • Changing colors and fonts
  • Page layouts and spacing
  • Basic web page design principles

I chose this video because learning HTML and CSS is essential for web development and portfolio building. It helped me better understand how websites are visually created and organized.

2. JavaScript Basics for Beginners

This video teaches the fundamentals of JavaScript, one of the most important programming languages used in web development. JavaScript allows websites to become interactive and dynamic.

The video covers concepts including:

  • Variables and data types
  • Functions and events
  • Loops and conditionals
  • User interaction
  • Basic problem solving with code

I selected this video because JavaScript is used in almost every modern website. Understanding JavaScript is important for creating interactive applications and improving front-end development skills.

3. Python Programming Tutorial

This video introduces Python programming and explains how Python is used in many areas of computer science such as software engineering, automation, artificial intelligence, cybersecurity, and data analysis.

Some of the topics explained in the tutorial include:

  • Variables and input/output
  • Loops and conditional statements
  • Functions and organization of code
  • Working with lists and dictionaries
  • Writing beginner-friendly programs

I chose this video because Python is considered one of the most beginner-friendly programming languages. It is also highly valuable in the technology industry because of its versatility and readability.
